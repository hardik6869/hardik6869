## 🚀 Featured Project: LearnHub

A full-stack academy directory where learners discover coding academies and courses and leave reviews, publishers manage their own listings, and admins moderate users and content.

**Built with:** React 19, TypeScript, Express 5, MongoDB, TanStack Query, Tailwind CSS, shadcn/ui, React Hook Form, Zod

**Key features:** role-based access for users, publishers, and admins · JWT authentication with password reset · secured REST API · search, filtering, sorting, and pagination
